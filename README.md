# SocialSpark

**Affordable, data-driven social media marketing for small businesses, student entrepreneurs, local brands, and startups.**

SocialSpark is a social media marketing agency built to help smaller businesses create a strong digital presence without a big budget. Instead of generic, one-size-fits-all packages, we design customized strategies based on each brand's audience, goals, and performance data.

We are starting with local businesses in **Dehradun**, helping them turn social media visibility into engagement, leads, and sales through consistent, relevant content.

## About This Project

This repository contains the SocialSpark app, built using [Google AI Studio](https://aistudio.google.com/).

### Run Locally

**Prerequisites:** Node.js

1. Install dependencies:
   ```bash
   npm install
   ```
2. Create a `.env.local` file and add your Gemini API key:
   ```
   GEMINI_API_KEY=your_api_key_here
   ```
3. Start the app:
   ```bash
   npm run dev
   ```

> Never commit your API key. Make sure `.env.local` is listed in `.gitignore`.
